## Overview

Afro-Tech is a professional training centre in Sudan offering a wide range of courses to the local community, and one of the country's most trusted training providers. It needed an e-learning website where people could discover its programmes and learn online.

## My role

Full-stack developer: the AngularJS front-end, the Node.js API and the database behind it.

## What I built

### The front-end

- An **AngularJS** single-page application for browsing the course catalogue and course details.
- Responsive views so learners can use the platform comfortably on phones as well as desktops.

### The API and data

- A **Node.js and Express** API with **20+ REST endpoints**, documented with request and response examples so the front-end could integrate quickly.
- A **MySQL** database for courses and related records.

## Technical highlights

- **SQL stored procedures** that fold multi-step queries into single calls, cutting network round trips and speeding up responses.
- A clean Express structure with separated routes, controllers and data access, easy to extend as the course catalogue grows.

## Outcome

An e-learning platform that lets the centre present its courses online and reach learners beyond its classrooms, built end to end from the database to the interface.
